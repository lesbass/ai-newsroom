## Regression found and fixed this run — untracked drafts polluted the local gate

The first run of today's gate reported `Links` and `Images` failures:

- `/articles/chrome-devtools-mcp-ai-coding-agents/` → broken absolute links to `https://news.lesbass.com/paperclip/AIN-346` and `AIN-348`
- Same page + `/articles/agent-reach-ai-agent-web-access-cli/` → unresolved `{{` template expression rendered as visible text

Root cause: the sandbox working tree contains **22 untracked, abandoned draft articles** under `src/content/articles/` (mtime 2026-09-13, never committed, none live — every live slug maps to a tracked source file). Astro builds whatever is in `src/content`, so these drafts were built into local `dist/` and surfaced in the local checks. They ship from a clean deploy checkout; the live site is unaffected and all 67 tracked sources pass.

Fix (commit `4d79b71`): `scripts/audit-daily.mjs` now builds and runs the file-based checks against an **isolated `git archive HEAD` export** (with a `node_modules` symlink) unless `AUDIT_WORKTREE=dirty` is set. The daily gate now validates the exact artifact that deploys and is immune to abandoned working-tree files. Re-run: 11/11 PASS. The abandoned drafts remain in the sandbox (harmless, inert) rather than being deleted, so no open article task loses its draft.
