# Nonexistent slashless URLs 404 instead of redirecting — 2026-10-23 (AIN-1048)

Canonical target: `https://news.lesbass.com/`.

## Defect

`src/worker.js` appended a trailing slash and returned a permanent `301` for
every dotless path before consulting the ASSETS binding. A mistyped or removed
URL therefore never 404'd directly:

```
GET /does-not-exist-xyz  ->  301 /does-not-exist-xyz/  ->  404
```

Search engines treat a redirect that resolves to a 404 as wasted crawl budget
and report it as an ambiguous redirect chain. The slashless canonicalisation
added in AIN-1047 fixed duplicate/`index.html` copies but kept this
unconditional redirect.

## Fix

The Worker now fetches ASSETS first for a slashless page route and inspects the
result. Cloudflare answers a slashless directory with `307 Location: <path>/`
only when the page exists, and with `404` when it does not. `slashlessPageTarget()`
converts that existing-page `307` into the canonical `301`; a missing page is
passed through as the real `404`. `_redirects` 301s and the `index.html` /
duplicate-slash rules are unchanged.

Side benefit: a slashless legacy `_redirects` source (for example
`/articles/smolagents-hugging-face-agenti-codice-python`) now resolves to its
canonical target in one hop instead of two.

## Verification

Local `wrangler dev` against the real `dist/` with the patched Worker:

| Request | Result |
|---|---|
| `/articles` | `301 -> /articles/` |
| `/articles/` | `200` |
| `/does-not-exist-xyz` | `404` (no redirect) |
| `/does-not-exist-xyz/` | `404` |
| `/index.html` | `301 -> /` |
| `//articles//` | `301 -> /articles/` |
| `/tags/agent-auth/` | `301 -> /tags/security/` |
| `/articles/smolagents-hugging-face-agenti-codice-python` | `301 -> /articles/smolagents-hugging-face-agents-code-python/` |
| `/rss.xml` | `200` |

`npm run test:worker` → 18/18, including new cases for existing-page 301s and
the nonexistent-page 404. `npx eslint src/worker.js scripts/check-worker.mjs` →
clean.

No content, canonical host, sitemap, RSS, or domain setting changed.
