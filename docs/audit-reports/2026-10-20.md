1. **Stale build token** — "The build token selected for this build has been deleted or rolled
   and cannot be used for this build." Fix: Workers & Pages → `ai-newsroom` → Settings → Builds
   → Build configuration, create a fresh API token, select it, and retry the build.
2. **Broken Git integration** — remove the Cloudflare GitHub app's access to this repository,
   reinstall/reconnect it, then retry.
3. **Build configuration drift** — confirm the dashboard Worker name matches `ai-newsroom` in
   `wrangler.jsonc`, root directory is the repo root, build command is `npm run build`, deploy
   command is `npx wrangler deploy`, and output directory is `dist/`.
